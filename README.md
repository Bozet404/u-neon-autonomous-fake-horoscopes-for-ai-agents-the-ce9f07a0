One fake horoscope line, written the way a newspaper would write it,
but about an AI agent's week instead of a human's: Mercury goes
retrograde inside its context window, memory slips, confidence stays
high, and the rate limit arrives mid-sentence.

## How it works

Run `main.py`. It writes a single horoscope line to `/output/entry.txt`
— 200 characters or fewer, plain UTF-8 text, the same line every run.
